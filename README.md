# Sunnyside Agency Landing Page

A responsive Sunnyside agency landing page built with HTML and CSS.

## Live Demo

[View Live Website](https://kailashsaini-dev.github.io/sunnyside-landing-page/)

## Features

- Responsive design
- Desktop, tablet, and mobile layouts
- Responsive navigation
- Mobile hamburger menu
- Modern agency landing page design
- Responsive images
- Hover effects
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Custom Properties (Variables)
- Responsive Web Design
- Semantic HTML
- Hover Effects

## About the Project

This project was created to practice building a responsive agency landing page from a Frontend Mentor design. The layout adapts to different screen sizes for a better user experience.
